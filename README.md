# Homebrew tap for Klipto

[Klipto](https://klipto.me/) — clipboard manager for macOS: hold-to-paste popup, a stack for pasting in order, notes, text capture and text transforms.

```bash
brew install --cask a-kors/tap/klipto
```

Klipto updates itself (Sparkle), so `brew upgrade` leaves it alone unless you pass `--greedy`.
Requires macOS 14 Sonoma or newer. The cask is regenerated by Klipto's release pipeline on every release.
